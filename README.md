# AiAi

## Codex specialist skills

This repository contains four reusable Codex skills under .agents/skills/:

- `java-coding-specialist` — Java programming, coursework, and debugging.
- `hackathon-specialist` — idea generation, MVP scoping, pitches, and preparation.
- `math-problem-specialist` — guided, checkable solutions to math problems.
- `trading-chart-specialist` — educational trading chart analysis and risk-aware scenarios.

In Codex, invoke one explicitly with `$java-coding-specialist`, `$hackathon-specialist`, `$math-problem-specialist`, or `$trading-chart-specialist`. Because these are in the repository's .agents/skills/ directory, Codex can also discover them while working in this repository.
